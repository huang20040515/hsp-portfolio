# 黄少鹏 · 个人作品集

短视频编导 / 内容运营 / AIGC 实践者个人作品集单页站点。

## 本地预览

直接用浏览器打开 `index.html`，或：

```bash
npx serve .
```

## 目录结构

```
index.html      # 单页站点（HTML/CSS/JS）
assets/
  hero-3d.png   # Hero 3D 插画
  cards-3d.png  # 项目卡片 3D 插画
```

## 技术说明

- 纯静态页面，无构建步骤
- 响应式布局，支持桌面与移动端
- 字体：Google Fonts（Fredoka + Noto Sans SC）
